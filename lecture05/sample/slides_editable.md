# 同じdataから、reportとslide

- `report.md` と `slides.md` は別のfile
- 図は共通の `figures/` を見る
- 記法は同じ。`---` で頁を区切るところだけが違う

**slideは箇条書きと図。reportの文章をそのまま貼ると入らない。**

# 日本

- 2016年3月にマイナス入り
- 最も低いのは2018年6月の −0.071%
- 2024年3月に解除、2026年7月は **0.978%**

マイナス金利は8年続きました。
