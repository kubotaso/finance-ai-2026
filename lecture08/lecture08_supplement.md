# 1. 決算を読む前に：会社・期間・グループ

## 決算は、会社の活動を一定期間で区切った記録です

会社は日々、商品を仕入れ、販売し、代金を受け取り、給与などを支払っています。決算では、こうした活動を一定期間で区切り、利益や期末の財産・負債をまとめます。その結果を表にしたものが財務諸表です。

通常、1年間の区切りを「事業年度」と呼びます。会社の1年間は、必ずしも1月から12月ではありません。今回の2026年2月期は、2025年3月1日から2026年2月28日までです。「2026年」は、その決算期間が終わる年を表します。

「通期」は事業年度全体、「四半期」は1年間を四つに分けた3か月の期間です。ただし、四半期の決算資料には、年度の初めからの累計値も載ります。半年分や9か月分の利益と、1年分の利益では、対象期間が異なります。

## 株主・親会社・子会社

株主は、会社の株式を持つ人や会社です。会社は株式の発行によって出資を受け、株主はその会社の持分を持ちます。出資は借入れと異なり、元本の返済期限がある資金ではありません。

ある会社の経営上の意思決定を支配している会社を「親会社」、支配される側を「子会社」と呼びます。例えば、議決権の過半数を持つと、通常はその会社の意思決定を支配できます。実際の判断では、持株比率だけでなく支配の実態も考慮します。

子会社は、親会社の一つの部署ではありません。それぞれ別の会社として、自分の資産・負債や決算を持っています。

他社の株式を持ち、グループ各社の経営を管理する会社を「持株会社」と呼びます。店舗を運営する子会社と、グループを管理する持株会社では、個別の決算に表れる活動が違います。

## 個別決算と連結決算

個別決算は一つの会社だけ、連結決算は親会社と連結対象の子会社を一つのグループとして見た決算です。「個別」は個人事業という意味ではありません。

| 比べる点 | 個別決算 | 連結決算 |
|---|---|---|
| 対象 | その会社一つです。 | 親会社と連結対象の子会社です。 |
| 子会社の売上や費用 | 親会社の売上や費用には直接合算しません。 | グループ内取引を調整したうえで含めます。 |
| 親会社から子会社への貸付け | 親会社には貸付金、子会社には借入金があります。 | グループ内部の貸し借りとして相殺します。 |
| 読み取る対象 | 一つの会社としての活動や財産です。 | グループ全体の事業や財産です。 |

持株会社の個別決算だけでは、子会社の店舗で上がった売上の全体は見えません。グループの事業規模を比べる今回の講義では、連結決算を使います。

連結対象の子会社は、持株比率が80%なら売上も80%だけ加える、という扱いではありません。売上や資産・負債は原則として全額を取り込み、他の株主に帰属する純資産や利益を分けて示します。この区別が、後に出てくる「非支配株主持分」や「親会社株主に帰属する当期純利益」につながります。

## 連結では、内部の取引を除きます

次は、連結の考え方を示す架空の例です。親会社がグループ外から80万円で仕入れた商品を、子会社へ100万円で売ります。子会社は、その商品をすべてグループ外のお客さんへ150万円で売ったとします。ほかの費用は省略します。

| 見方 | 売上 | 売上原価 | 利益 |
|---|---:|---:|---:|
| 親会社の個別決算 | 100万円 | 80万円 | 20万円 |
| 子会社の個別決算 | 150万円 | 100万円 | 50万円 |
| 単純に合計した場合 | 250万円 | 180万円 | 70万円 |
| 連結決算 | 150万円 | 80万円 | 70万円 |

親会社から子会社への100万円は、グループ内部の売買です。この売上と、それに対応する子会社の原価を除くと、外部への売上150万円と外部からの仕入原価80万円が残ります。内部取引を消して、一つの会社のように見る処理を「相殺消去」と呼びます。

この例では商品をすべて外部へ売っています。子会社に商品が残っている場合は、その在庫に含まれるグループ内部の利益も調整します。連結は、各社の数字を足すだけの作業ではありません。

参照：桜井『財務諸表分析』第9版、47〜49頁、70〜74頁、87〜90頁。数値例は本補足のために作成しています。

# 2. 三つの表で分かること

会社の姿は、持っている資産、稼いだ利益、実際のお金の動きを組み合わせると分かりやすくなります。[第8回の講義本文](lecture08.md)で取得する財務三表は、それぞれ次の役割を持っています。

| 表 | 分かること | 数字が表す時間 | 講義で使う主な変数 |
|---|---|---|---|
| 貸借対照表（B/S） | どんな資産を持ち、その資金をどう調達しているか | 決算日時点の残高 | `TA`、`Eq` |
| 損益計算書（P/L） | どれだけ収益を得て、費用を差し引くと利益がいくらになるか | 決算期間中の金額 | `Sales`、`OP`、`OdP`、`NP` |
| キャッシュ・フロー計算書（C/F） | どの活動でお金が入り、どの活動で出ていったか | 決算期間中の金額 | `CFO`、`CFI`、`CFF` |

2026年2月期の通期決算なら、貸借対照表は2026年2月28日の状態を示します。損益計算書とキャッシュ・フロー計算書は、2025年3月1日から2026年2月28日までの動きを示します。

ある時点の残高を「ストック」、一定期間の動きを「フロー」と呼びます。現金の期末残高 `CashEq` は、キャッシュ・フロー計算書に載っていますが、ストックです。載っている表の名前だけでなく、その項目が何を表すかで区別します。

参照：桜井『財務諸表分析』第9版、5〜9頁、99〜104頁。

# 3. 貸借対照表：資産と、その資金の出所

## 資産・負債・純資産

資産には、現金だけでなく、商品、店舗、設備、販売代金を受け取る権利なども含まれます。総資産が大きいということは、会社が事業に使う経済的な資源が多いということです。

負債には、借入金のほか、仕入代金の未払額である買掛金なども含まれます。純資産には、株主からの出資や、これまでの利益のうち配当などで社外に出さずに残した部分などが含まれます。

$$
\text{総資産} = \text{負債} + \text{純資産}
$$

この式は、資金の使い道と出所を同じ金額で捉える関係です。例えば、現金100万円を借り入れると、資産の現金と負債の借入金が、ともに100万円増えます。

講義で取得したセブン＆アイの2026年2月期では、総資産 `TA` は9,142,957百万円、純資産 `Eq` は3,648,195百万円です。したがって、負債の合計は次のように計算できます。

$$
9{,}142{,}957 - 3{,}648{,}195 = 5{,}494{,}762\quad\text{（百万円）}
$$

内訳は決算短信の貸借対照表で確認できます。

## 内訳を見ると分かること

| 分類 | 主な項目 | 読み取れること |
|---|---|---|
| 流動資産 | 現金及び預金、売掛金、商品 | 日々の営業や比較的短い期間の資金回収に関わる資産です。 |
| 固定資産 | 建物、土地、設備、のれん | 長く使う資産や、企業の買収に関連する資産などです。 |
| 流動負債 | 買掛金、短期借入金 | 日々の営業に伴う支払義務や、近く返済期限が来る負債です。 |
| 固定負債 | 長期借入金、社債 | 返済まで比較的長い期間がある負債です。 |
| 純資産 | 株主資本、その他の包括利益累計額、非支配株主持分など | 資産から負債を差し引いた部分の構成です。 |

流動・固定の区分には、通常の営業の循環に含まれるかどうかと、原則として1年以内かどうかを使います。

純資産は、現金を別に積み立てた金額ではありません。例えば、過去の利益を使って店舗を建てれば、その資金は建物という資産に変わっています。

また、連結の純資産には、子会社の株主のうち親会社以外の株主に帰属する部分も含まれます。親会社の株主に帰属する「自己資本」と、純資産全体は区別されます。講義の `Eq` は純資産です。

参照：同書、47〜54頁、55〜58頁、62〜74頁。

# 4. 損益計算書：収益から利益まで

## 収益と利益は違う数字です

収益は、商品やサービスの提供などから得られる成果を金額で表したものです。そこから費用を差し引いた残りが利益です。

例えば、仕入原価60万円の商品を100万円で販売すると、売上総利益は40万円です。店舗の家賃や従業員の給与などが25万円なら、営業利益は15万円になります。ここでは、ほかの収益や費用がない場合を考えています。

費用をどこまで含めるかに応じて、利益の名前が変わります。次の表は、日本基準の損益計算書の基本的な流れです。

| 利益の段階 | 計算の考え方 | 講義との対応 |
|---|---|---|
| 売上総利益 | 売上高 − 売上原価 | 商品などの販売価格と原価の差です。 |
| 営業利益 | 売上総利益 − 販売費及び一般管理費 | 本業からの利益で、`OP` に対応します。 |
| 経常利益 | 営業利益 ＋ 営業外収益 − 営業外費用 | 利息なども反映した利益で、`OdP` に対応します。 |
| 税金等調整前当期純利益 | 経常利益 ＋ 特別利益 − 特別損失 | 資産の売却損益なども反映します。 |
| 当期純利益 | 税金等調整前当期純利益 − 税金費用 | 連結グループ全体の税引後の利益です。 |
| 親会社株主に帰属する当期純利益 | 当期純利益 − 非支配株主に帰属する当期純利益 | 親会社の株主に帰属する利益で、`NP` に対応します。 |

特別損益には、固定資産の売却損益や災害損失などが含まれます。どの段階で利益が増減したかを見ると、その理由を絞り込めます。

## セブン＆アイの「営業収益」

セブン＆アイの損益計算書には、「売上高」と「営業収入」があり、その合計が「営業収益」です。営業収入には、フランチャイズの加盟店から得る収入などが含まれます。営業収益から売上原価を引いたものが営業総利益で、そこから販売費及び一般管理費を引くと営業利益になります。

今回のJ-Quantsの `Sales` は営業収益に対応します。決算短信の「売上高」だけと比較すると、範囲が異なります。変数名が `Sales` でも、対応する公表項目の名前と中身を確認することに意味があります。

講義の取得値では、2025年2月期から2026年2月期にかけて、営業収益は減り、営業利益はほぼ横ばいで、純利益は増えています。この三つを分けて読むと、「収入規模の変化」と「最終的な利益の変化」を区別できます。原因は決算短信の内訳や説明に戻って確かめます。

参照：同書、75〜85頁、87〜90頁。講義の企業数値は今回の取得データによります。

# 5. キャッシュ・フロー計算書：お金の出入り

## 三つの活動に分ける

キャッシュ・フロー計算書は、現金及び現金同等物の増減を説明します。現金同等物は、容易に換金でき、価値が大きく変わるリスクが小さい短期の運用資産です。貸借対照表の「現金及び預金」とは対象範囲が異なる場合があります。

| 区分 | 主な流入の例 | 主な流出の例 | 変数 |
|---|---|---|---|
| 営業活動 | 販売代金の回収 | 仕入代金、給与、税金の支払い | `CFO` |
| 投資活動 | 設備や投資有価証券の売却 | 設備や投資有価証券の取得 | `CFI` |
| 財務活動 | 借入れ、株式の発行 | 借入金の返済、配当、自己株式の取得 | `CFF` |

正の値は、その区分で流入が流出を上回ったことを示します。負の値は、その逆です。

投資CFが負でも、店舗や設備に積極的に投資している場合があります。財務CFが負なら、借入金の返済や株主への還元が進んでいる場合があります。

営業CFの金額には、売掛金の回収や仕入代金の支払いの時期も影響します。

## 利益とお金が一致しない理由

商品を販売しても、代金を翌月に受け取るなら、売上の計上と入金は別の時点になります。また、設備の購入では、購入時の支払いと、その設備を使う期間の費用計上が分かれます。

| 出来事 | 利益への反映 | 現金への反映 |
|---|---|---|
| 代金を後で受け取る販売 | 売上と、それに対応する原価を計上します。 | まだ入金されません。未収の代金は売掛金になります。 |
| 過去の売掛金を回収 | すでに計上した売上なので、回収時にもう一度利益は生じません。 | 営業活動の入金になります。 |
| 長く使う設備を購入 | 資産に計上し、使用期間に費用を配分します。 | 購入代金の支払いは投資活動の出金です。 |
| 減価償却費を計上 | 設備などの取得額の一部を費用として配分します。 | 費用計上そのものでは現金は出ません。 |
| 借入れ・元本の返済 | 元本の受取りや返済自体は利益に入りません。 | 財務活動の入金・出金になります。 |

営業CFを利益から調整して求める表示方法を「間接法」と呼びます。減価償却費などの現金支出を伴わない費用や、売掛金・棚卸資産・買掛金の増減などを調整します。

## 現金残高とのつながり

$$
\text{期末の現金及び現金同等物}
= \text{期首の現金及び現金同等物}
+ \text{CFO} + \text{CFI} + \text{CFF}
+ \text{その他の増減}
$$

その他の増減には、海外子会社の現金を円に換算する際の為替の影響や、連結範囲の変化などがあります。三つのCFの合計と現金残高の増減が違うときは、キャッシュ・フロー計算書の末尾にある項目を確認できます。

参照：同書、99〜110頁、110〜115頁。

# 6. 小さな例で三表をつなぐ

以下は、この補足のために作った架空の会社の例です。単位は万円です。期首に現金200、純資産200があり、負債はありません。税金・利息・配当は省略します。

| 1年間の出来事 | 金額 |
|---|---:|
| 銀行から借り入れます。 | 100 |
| 商品を現金で仕入れます。 | 80 |
| 設備を現金で購入します。 | 120 |
| 仕入原価50の商品を、90で販売します。 | 売上90、売上原価50 |
| 販売代金90のうち、60を回収します。 | 入金60、未回収30 |
| 設備について減価償却費を計上します。 | 12 |

## 損益計算書では利益28です

売上90から売上原価50と減価償却費12を引くと、利益は28です。購入した商品のうち、まだ売っていない30は、費用ではなく期末の商品として残ります。

$$
\text{利益} = 90 - 50 - 12 = 28
$$

## キャッシュ・フロー計算書では現金が40減ります

| 区分 | 計算 | 金額 |
|---|---|---:|
| 営業CF | 販売代金の回収60 − 商品仕入れの支払い80 | −20 |
| 投資CF | 設備購入の支払い | −120 |
| 財務CF | 借入れによる入金 | 100 |
| 現金の増減 | −20 −120 ＋100 | −40 |

期首の現金200から40減るので、期末の現金は160です。利益が28生じても、現金は減っています。商品の仕入れ、代金の未回収、設備購入があるためです。

## 貸借対照表では両側が328になります

| 資産 | 金額 | 負債・純資産 | 金額 |
|---|---:|---|---:|
| 現金 | 160 | 借入金 | 100 |
| 売掛金 | 30 | 純資産 | 228 |
| 商品 | 30 | | |
| 設備（取得額120 − 減価償却12） | 108 | | |
| 合計 | 328 | 合計 | 328 |

この例では、純資産は期首200に利益28を加えた228です。現金の変化はCFで、純資産の変化は利益で説明できます。実際の会社では、純資産は配当、増資、自己株式の取得、評価・換算差額などでも変動します。

三表をつないで見ると、「利益が出た」と「現金が増えた」が違う意味だと分かります。

考え方の参照：同書、102〜106頁。上の取引設定・数値・表は本補足独自の例です。

# 7. 取得データと決算短信をどう読むか

## 決算短信・有価証券報告書・説明資料の違い

会社は、同じ決算についても、目的の違う資料を公表します。財務諸表は「数字を示す表」、決算短信や有価証券報告書は「その表や説明を載せる資料」です。財務諸表と資料の名前を分けて考えると、探す場所が分かりやすくなります。

| 公表物 | 主な内容と役割 | どんなときに読むか |
|---|---|---|
| 決算短信 | 決算の概要を早く伝える資料です。売上・利益、財政状態、配当、業績予想、財務諸表などを載せます。 | 決算の全体像をつかみ、主要な数値を確認するときに読みます。 |
| 有価証券報告書（有報） | 年度ごとの詳しい報告書です。事業内容、リスク、従業員、株式、経営体制、財務諸表と注記などを載せます。 | 数値の細かな内訳や会計処理、事業のリスクまで調べるときに読みます。 |
| 半期報告書 | 年度の前半6か月についての報告書です。中間財務諸表や事業の状況などを載せます。 | 年度の途中で業績や財政状態を確認するときに読みます。 |
| 決算説明資料・決算補足資料 | 業績の増減要因、事業別の実績、店舗数などを図表で説明します。名称や構成は会社によって違います。 | 売上や利益が変化した理由を理解するときに読みます。 |
| 統合報告書 | 事業の強み、中長期の戦略、人材や環境への取り組みなどを、財務情報と結び付けて説明します。 | 会社がどのように将来の価値を生み出そうとしているかを読むときに使います。 |
| 株主総会の招集通知・総会資料 | 総会の日時や議案、事業報告、計算書類などを確認する資料です。 | 取締役の選任や配当など、株主として判断する内容を調べるときに読みます。 |
| 業績予想の修正・買収などの適時開示資料 | 決算の時期に限らず、投資判断に関わる出来事を公表します。 | 前の決算発表から何が変わったかを確認するときに読みます。 |

桜井の教科書は、会社法の計算書類、金融商品取引法の報告書、取引所での決算発表を分けて説明しています。有価証券報告書・半期報告書は法律に基づく報告書で、決算短信は取引所のルールに基づく開示です。説明資料や統合報告書には、会社が理解を深めてもらうために工夫した説明が載ります。参照：同書、13〜23頁。[決算説明資料の位置づけ（JPX）](https://faq.jpx.co.jp/disclo/tse/web/knowledge8240.html)、[セブン＆アイの各種IR資料](https://www.7andi.com/ir/library.html)。

## 決算短信と有価証券報告書は、詳しさと公表の目的が違います

決算短信は、決算の内容を早く知らせる役割を持っています。監査の終了を待たずに公表される場合もあります。有価証券報告書では、財務諸表の詳しい注記や監査報告書も確認できます。監査は、公認会計士などが財務諸表の適正さについて意見を示す手続きです。参照：同書、17〜23頁。[決算発表と監査の関係（JPX）](https://faq.jpx.co.jp/disclo/tse/web/knowledge7142.html)。

例えば、借入金の合計を知りたいときは、まず決算短信の貸借対照表を見ます。返済期限などを詳しく知りたいときは、有価証券報告書の注記や附属明細表を見ます。利益が減った背景をつかみたいときは、決算説明資料の増減要因の図も役立ちます。

決算短信にも有価証券報告書にも、連結と個別の数字が載ることがあります。

## 四半期の資料と半期報告書

「第1四半期決算短信」などは、年度途中の決算を知らせる資料です。「四半期決算短信」と「四半期報告書」は別の制度の書類です。

2024年の制度改正で、金融商品取引法上の四半期報告書は廃止され、上場会社の年度途中の法定報告は半期報告書へ移りました。一方、第1・第3四半期の決算短信による開示は続いています。過去の資料室には四半期報告書も残るため、資料の年度によって名称が違います。[制度改正の説明（金融庁）](https://www.fsa.go.jp/frtc/kikou/2024/20240601_kigyoukaikei.pdf)。

## 公表資料をどこで探すか

会社のウェブサイトでは、「IR」や「株主・投資家情報」のページに資料がまとまっています。IRは Investor Relations の略で、会社が株主や投資家に情報を伝え、対話する活動です。例えば、[セブン＆アイのIR資料室](https://www.7andi.com/ir/library.html)には、決算短信、補足資料、説明資料、有価証券報告書、統合報告書が分かれて掲載されています。

有価証券報告書や半期報告書は、金融庁の[EDINET](https://disclosure2.edinet-fsa.go.jp/)でも検索できます。決算短信や業績予想の修正などは、取引所の[適時開示情報閲覧サービス（TDnet）](https://www.jpx.co.jp/listing/disclosure/01.html)からも確認できます。いずれも資料を探すための仕組みで、報告書そのものの名前ではありません。[EDINETの説明（金融庁）](https://www.fsa.go.jp/search/20130917.html)。

J-Quantsは、企業の公表情報をデータとして取得するために使っています。講義では、取得した値を表にして全体を捉え、決算短信で内訳を読みます。理由が分かりにくい場合は説明資料へ、細かな会計上の情報が必要なら有価証券報告書へと読み進められます。

# 8. 収益性：利益を資産や自己資本と比べる

## ROEと平均自己資本

ROEは Return on Equity の略で、「自己資本利益率」です。株主の持分に対して、1年間にどれだけ利益を上げたかを表します。連結決算では、親会社株主に帰属する当期純利益と、親会社の株主に帰属する自己資本を対応させます。

純利益は1年間の金額ですが、自己資本はある時点の残高です。このため、第9回の2社比較では、期首と期末の自己資本の平均を使います。

$$
\text{平均自己資本}=\frac{\text{期首自己資本}+\text{期末自己資本}}{2}
$$

$$
\text{ROE（%）}=\frac{\text{親会社株主に帰属する当期純利益}}{\text{平均自己資本}}\times100
$$

例えば、期首自己資本が400万円、期末が600万円、純利益が50万円なら、平均自己資本は500万円、ROEは10%です。期末だけを使うと約8.33%になります。利益が同じでも、分母の選び方で値は変わります。

平均残高は、期中に使った資本を近似する方法です。前期比較値が修正されている場合は、同じ決算短信に載る期首・期末の値を使うと、会計上の基準をそろえやすくなります。

J-Quantsでは、純利益は `NP`、自己資本は `ShEq`、純資産全体は `Eq` です。第9回後半の多数企業の作例では、簡便に期末自己資本を使っています。平均自己資本によるROEとは計算条件が違います。

## デュポン分解

デュポン分解は、ROEを「利益率」「資産の使い方」「資本の構成」の三つに分ける方法です。

| 指標 | 計算 | 読み取れること |
|---|---|---|
| 売上高純利益率 | 純利益÷売上高 | 売上のうち、最終的な利益として残る割合です。 |
| 総資産回転率 | 売上高÷平均総資産 | 資産の規模に対して、どれだけ売上を上げたかを表します。 |
| 財務レバレッジ | 平均総資産÷平均自己資本 | 自己資本に対する資産の倍率です。借入金だけの倍率ではありません。 |

$$
\text{ROE}=\text{売上高純利益率}\times\text{総資産回転率}\times\text{財務レバレッジ}
$$

利益率が4%、回転率が1.25回、レバレッジが2倍なら、ROEは0.04×1.25×2＝0.10、つまり10%です。計算途中では4%を0.04として扱います。

同じROEでも、利益率が高い会社と、レバレッジが高い会社では成り立ちが違います。レバレッジが高いほど、利益や損失の変化が自己資本に対して大きく表れやすくなります。

第9回では売上高に相当する値として営業収益 `Sales` を使います。総資産 `TA` にも期首・期末平均を使います。銀行業などを含む会社では資産や負債の構成が異なるため、事業内容と合わせて読みます。

参照：桜井『財務諸表分析』第9版、第8章、169〜172頁、181〜184頁。数値例は本補足のための架空の例です。

# 9. 市場評価：1株の数値と株価を比べる

## 株価・EPS・BPS

株価は、市場で取引される1株の価格です。終値は、その日の最後に成立した取引の価格です。会社の決算から直接決まる値ではなく、将来への期待なども反映します。

EPSは Earnings per Share の略で、「1株当たり純利益」です。BPSは Book-value per Share の略で、「1株当たり自己資本」です。決算短信ではBPSを「1株当たり純資産」と表記します。

EPSは1年間などの利益を、BPSは期末の自己資本を1株当たりに直します。基本的な計算では、EPSに期中平均の株式数、BPSに期末の株式数を使います。どちらも自己株式を除きます。自己株式は、会社が保有する自社の株式です。

講義では、公表された実績の `EPS` と `BPS` を使います。実績EPSは終了した期間の利益、予想EPSは今後の利益の見通しに基づきます。同じ株価でも、どちらを分母にするかで倍率は変わります。

## PERとPBR

| 指標 | 英語の名称 | 計算 | 意味 |
|---|---|---|---|
| PER（株価収益率） | Price Earnings Ratio | 株価÷EPS | 1株当たり利益の何倍の株価が付いているかを表します。 |
| PBR（株価純資産倍率） | Price Book-value Ratio | 株価÷BPS | 1株当たり自己資本の何倍の株価が付いているかを表します。 |

株価が2,000円、EPSが100円、BPSが1,000円なら、PERは20倍、PBRは2倍です。PERは名称に「率」が入りますが、ここでは%ではなく倍で表示します。

PER20倍は、20年で投資額を回収できるという意味ではありません。利益がそのまま配当されるわけではなく、将来の利益も変化するためです。

PBR1倍は、株価と1株当たりの帳簿上の自己資本が等しい状態です。低い倍率には将来への懸念、高い倍率には成長期待などが関係する場合があります。

赤字でEPSが負なら、この講義ではPERを空欄にします。その場合も、BPSが正ならPBRは計算できます。欠損とゼロを区別し、指標ごとに計算できた会社数を確認します。

参照：同書、第14章、301頁。数値例は本補足のための架空の例です。

## 株式分割と株数の基準

株式分割は、1株を複数の株に分けることです。1株を2株に分けると、株式数は2倍になります。分割だけで会社全体の利益や自己資本が2倍になるわけではありません。

他の条件が同じなら、1株当たりの価値は半分になります。株価2,000円、EPS100円、BPS1,000円を分割後の基準にそろえると、それぞれ1,000円、50円、500円です。PER20倍、PBR2倍は変わりません。実際の市場価格は、分割以外の要因でも動きます。

分割後の株価と分割前のEPSを組み合わせると、倍率を誤って計算します。決算短信がすでに分割を反映している場合は、さらに同じ調整を加える必要はありません。

講義で使う `C` はその日に付いた調整前終値です。過去の株価を分割などに合わせて直した調整後株価とは区別します。株価とEPS・BPSが同じ株数の基準かを確認してから比べます。

# 10. 会社を並べた表と図の読み方

## 評価日と比較対象

評価日は、株価を比較する基準の日です。決算期間の終わりや開示日とは異なります。例えば6月30日の市場評価を調べるなら、その時点で公表されていた決算情報と組み合わせます。

銘柄コードは会社の表記揺れに左右されず、表を結ぶための手掛かりになります。ただし、決算表には同じ会社の複数年度や複数の開示があるため、コードだけでなく対象期間と開示日もそろえます。

候補10社のうち5社しか条件に合わなければ、結果はその5社についての比較です。残る5社がなぜ入らないかを記録すると、集計の範囲が分かります。候補の選び方や欠損によって、平均や分布も変わります。

## 平均と中央値

平均は、値の合計を社数で割ったものです。中央値は、値を小さい順に並べたときの中央の値です。社数が偶数なら、中央の二つの値の平均を取ります。

例えばPERが10倍、12倍、14倍、16倍、100倍なら、平均は30.4倍、中央値は14倍です。平均は大きく離れた値の影響を受けます。両方と社数を並べると、集計の特徴をつかみやすくなります。

## ヒストグラム・散布図・対数目盛

ヒストグラムは、値を区間に分け、各区間に何社あるかを示す図です。会社が多く集まる範囲や、値の広がりを見ます。

散布図は、一つの点で一社の二つの指標を表します。第9回では横軸がROE、縦軸がPBRです。右上に点が集まる傾向があっても、ROEの上昇がPBRを上げたという因果関係を、それだけで示すことはできません。

対数目盛では、同じ倍率の変化が同じ間隔になります。例えばPBRの0.5倍から1倍、1倍から2倍、2倍から4倍は等間隔です。値の差ではなく倍率を見比べやすくなります。通常の対数目盛ではゼロや負の値を表示できません。

第9回の多数企業の散布図は930社中910社を表示し、中央値などは930社全体から計算しています。図に見える社数と集計の社数を区別します。

この節の数値例と図の読み方は、講義の比較条件に合わせた補足です。

| 有形固定資産 | 建物、土地、設備など、形のある長期使用資産です。 |
| のれん | 買収した事業の取得対価が、識別できる資産と負債の正味の価値を上回る部分などです。 |
| 負債 | 返済や支払いなどの義務です。講義では合計を `TA − Eq` で計算します。 |
| 買掛金 | 商品などを仕入れ、代金を後で支払う義務です。 |
| 有利子負債 | 借入金や社債など、利息を伴う負債です。負債全体とは範囲が異なります。 |
| 純資産 | 資産から負債を差し引いた部分です。`Eq` に対応します。 |
| 利益剰余金 | 過去の利益のうち、配当などを経て会社に残っている累積額です。現金残高とは異なります。 |
| 自己資本 | 連結では親会社の株主に帰属する持分です。純資産全体とは区別します。 |
| 非支配株主持分 | 子会社の純資産のうち、親会社以外の株主に帰属する部分です。 |

## 損益計算書とキャッシュ・フロー計算書

| 用語 | 意味・講義での対応 |
|---|---|
| 収益 | 商品やサービスの提供などによる成果を金額で表したものです。入金と同時とは限りません。 |
| 営業収益 | セブン＆アイでは売上高と営業収入の合計です。今回の `Sales` に対応します。 |
| 費用 | 利益を得るために消費した資源などを金額で表したものです。支払いと同時とは限りません。 |
| 売上原価 | 販売した商品や製品に対応する原価です。仕入額の全額が直ちに費用になるわけではありません。 |
| 販売費及び一般管理費 | 販売や経営管理にかかる費用です。「販管費」とも呼びます。 |
| 営業利益 | 本業の収益から、それに対応する費用を引いた利益です。`OP` に対応します。 |
| 営業外損益 | 受取利息や支払利息など、本業以外の収益・費用です。 |
| 経常利益 | 営業利益に営業外損益を加減した利益です。`OdP` に対応します。 |
| 特別損益 | 固定資産の売却損益など、主に臨時的な利益・損失です。 |
| 親会社株主に帰属する当期純利益 | 税金などを反映した後、親会社の株主に帰属する利益です。講義の純利益 `NP` はこれを指します。 |
| 減価償却 | 設備などの取得額を、使用する期間に配分して費用にすることです。 |
| キャッシュ・フロー（CF） | 現金及び現金同等物の流入と流出です。 |
| 営業CF | 営業活動などによる資金の増減です。`CFO` に対応します。 |
| 投資CF | 設備や投資資産の取得・売却などによる資金の増減です。`CFI` に対応します。 |
| 財務CF | 借入れ・返済や株主との資金のやり取りなどによる増減です。`CFF` に対応します。 |
| 現金及び現金同等物 | CF計算書で増減を捉える資金の範囲です。期末残高は `CashEq` に対応します。 |
| 間接法 | 利益に現金支出を伴わない費用や債権・債務の増減などを調整し、営業CFを求める方法です。 |
| 配当・自己株式の取得 | 配当は株主への利益の分配などです。自己株式の取得は会社が自社株を買うことです。支払いは財務CFに表れます。 |

## 収益性・市場評価・図の読み方

| 用語 | 意味・講義での対応 |
|---|---|
| 平均残高 | ここでは期首と期末の残高の平均です。期中に使った資産や資本を近似します。 |
| ROE（Return on Equity） | 自己資本利益率です。親会社株主の純利益を自己資本と比べます。分母が平均か期末かを確認します。 |
| デュポン分解 | ROEを売上高純利益率・総資産回転率・財務レバレッジの積に分ける方法です。 |
| 売上高純利益率 | 売上高に対する純利益の割合です。講義では営業収益を分母に使います。 |
| 総資産回転率 | 平均総資産に対する売上高の倍率です。単位は回です。 |
| 財務レバレッジ | 平均自己資本に対する平均総資産の倍率です。単位は倍です。 |
| 自己株式 | 会社が保有する自社の株式です。EPS・BPSの計算に使う株式数から除きます。 |
| EPS（Earnings per Share） | 1株当たり純利益です。基本的には期中平均株式数で計算します。`EPS` に対応します。 |
| BPS（Book-value per Share） | 1株当たり自己資本です。期末株式数で計算します。`BPS` に対応します。 |
| PER（Price Earnings Ratio） | 株価収益率です。株価÷EPSで求め、倍で表示します。 |
| PBR（Price Book-value Ratio） | 株価純資産倍率です。株価÷BPSで求め、倍で表示します。 |
| 株式分割 | 1株を複数の株に分けることです。株価と1株当たり指標の株数基準をそろえます。 |
| 終値・調整前終値 | その日の最後に成立した取引の価格です。講義の `C` は分割などで過去に遡って直す前の値です。 |
| 調整後株価 | 株式分割などを考慮し、過去の株価の基準をそろえた値です。 |
| 評価日 | 株価を比較する基準の日です。決算期末や開示日とは区別します。 |
| 欠損値 | 必要な値が得られていない状態です。ゼロとは異なります。 |
| 平均・中央値 | 平均は合計÷件数、中央値は値を順に並べた中央の値です。 |
| ヒストグラム | 値を区間に分け、その区間の件数を示す図です。 |
| 散布図 | 一つの点で二つの指標の組を示す図です。講義では一つの点が一社です。 |
| 対数目盛 | 同じ倍率の変化を同じ間隔で示す目盛です。 |
| 相関と因果 | 一緒に変化する傾向と、一方が他方を変化させる関係は異なります。 |
