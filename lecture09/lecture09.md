# 運転資金と設備資金

## 利益が出ていても現金が足りなくなる

日々の営業では、仕入れ・販売と、お金の受け払いの時点がずれます。

- 売掛金：商品を売ったが、代金をまだ受け取っていない金額
- 在庫：販売に備えて手元に置いている商品
- 買掛金：商品を仕入れたが、代金をまだ払っていない金額

代金を手形で受け取る・払う場合（受取手形・支払手形）も、売掛金・買掛金と同じく時点のずれを生みます。手形は、指定した期日に代金を支払うことを約束した証書です。

ある小売店が、毎月80万円で商品を仕入れて100万円で売るとします。仕入れの代金は1か月後に払い、売上の代金は2か月後に受け取ります。販売は4か月目まで続け、在庫は残らないとします。単位は万円です。

| 月 | 利益の累計 | 売掛金 | 買掛金 | 運転資金 | 現金の累計 |
|---:|---:|---:|---:|---:|---:|
| 1 | 20 | 100 | 80 | 20 | 0 |
| 2 | 40 | 200 | 80 | 120 | -80 |
| 3 | 60 | 200 | 80 | 120 | -60 |
| 4 | 80 | 200 | 80 | 120 | -40 |
| 5 | 80 | 100 | 0 | 100 | -20 |
| 6 | 80 | 0 | 0 | 0 | 80 |

$$
\text{運転資金} = \text{売掛金} + \text{在庫} - \text{買掛金}
$$

利益が出ていても、運転資金の分だけ現金は少なくなります。 どの月も、現金の累計は、利益の累計から運転資金を引いた値です。2か月目の終わりには、利益が40万円あるのに、現金は80万円足りません。この不足を借入などで埋められないと、黒字のまま支払いができなくなります。これが黒字倒産です。

売上の入金を1か月後に早めると、現金が足りない月はなくなります。在庫を持つと、その分だけ運転資金が増えます。Codexに入金の時期や在庫を変えて計算するよう頼むと、現金の動きがどう変わるかを比べられます。

## 設備資金

機械や建物のように、何年も使うものを買うための資金が設備資金です。運転資金は営業を続ける間ずっと必要で、仕入れと入金を繰り返しながら回ります。設備資金は、買うときに大きな金額が一度に出て、何年もかけて売上から回収します。設備の代金をどう記録するかは、減価償却の節で扱います。

# 内部資金と外部資金

会社の資金の集め方は、会社の中にあるお金を使うか、外から集めるかで分けられます。まとめると、次のようになります。

| 方法 | 内部・外部 | 返済 | 支払い | 経営への参加 | B/Sのどこに出るか |
|---|---|---|---|---|---|
| 利益の留保 | 内部 | なし | なし | 株主は変わらない | 純資産（利益剰余金） |
| 株式の発行 | 外部 | なし | 利益があれば配当 | 新しい株主が議決権を持つ | 純資産（資本金など） |
| 社債 | 外部 | 満期に返す | 利息 | なし | 負債 |
| 銀行借入 | 外部 | 期限に返す | 利息 | なし | 負債 |
| 企業間信用 | 外部 | 支払期日に払う | 通常は利息なし | なし | 負債（買掛金など） |

株式と社債は、市場で多くの投資家から集めます。銀行借入は、銀行と1対1で契約します。企業間信用は、取引先に代金の支払いを待ってもらうことで生まれる資金で、小売店の例の買掛金がこれにあたります。

利益の留保は、その年の利益から税金や配当を払った残りを、会社に残すことです。B/Sでは、利益剰余金として純資産に積み上がります。

# B/S：ある時点の資産・負債・純資産

B/S（Balance Sheet、貸借対照表）は、期末など、ある時点の財産の状態を表します。左側の資産は資金の使い道、右側の負債と純資産は資金をどこから集めたかです。

$$
\text{資産} = \text{負債} + \text{純資産}
$$

架空の会社の例です。単位は百万円です。

| 資産 | 金額 | 負債・純資産 | 金額 |
|---|---:|---|---:|
| **流動資産** | | **負債** | |
| 　現金 | 50 | 　買掛金 | 80 |
| 　売掛金 | 120 | 　銀行借入 | 150 |
| 　在庫 | 30 | 負債合計 | 230 |
| **固定資産** | | **純資産** | |
| 　機械 | 200 | 　資本金 | 100 |
| | | 　利益剰余金 | 60 |
| | | 　非支配株主持分 | 10 |
| | | 純資産合計 | 170 |
| 資産合計 | 400 | 負債・純資産合計 | 400 |

各項目の意味です。

| 項目 | 意味 |
|---|---|
| 資産 | 集めた資金の使い道。左側に並びます |
| 流動資産 | 1年以内に現金になる資産 |
| 現金 | そのまま支払いに使えるお金 |
| 売掛金 | 売ったが、まだ受け取っていない代金 |
| 在庫（棚卸資産） | 売るために持っている商品 |
| 固定資産 | 1年を超えて使う資産 |
| 機械 | 何年も使う設備。減価償却で簿価が減ります |
| 負債 | 返す義務のある資金。期限までに返します |
| 買掛金 | 仕入れたが、まだ払っていない代金。1年以内に払うので流動負債です |
| 銀行借入 | 銀行から借りた資金。期限に返し、利息を払います。返済期限が1年より先なら固定負債です |
| 純資産 | 返す義務のない資金 |
| 資本金 | 株主が払い込んだ資金 |
| 利益剰余金 | 過去の利益のうち、配当せずに会社に残した分 |
| 非支配株主持分 | 子会社の純資産のうち、親会社以外の株主の分 |

左右に分ける意味は、資産400百万円をどこから来た資金で賄っているかが右側で分かることです。この会社は、そのうち230百万円を返す義務のある負債で、170百万円を返す義務のない純資産で賄っています。

## 純資産と自己資本

連結決算では、子会社の株式を親会社以外の株主も持っていることがあります。その株主の分が非支配株主持分で、純資産に入ります。純資産から非支配株主持分などを除いた、親会社の株主の分が自己資本です。IFRSの決算短信では「親会社の所有者に帰属する持分」と書かれます。

上の例では、純資産170百万円のうち自己資本は160百万円です。総資産に対する比率は、純資産で42.5%、自己資本で40.0%です。

## 簿価と時価

B/Sの純資産は、払い込まれた資本と積み上げた利益を、帳簿の価格で記録したもの（簿価）です。株式の時価総額は、市場で付いた株価に発行済株式数を掛けたもの（時価）です。2つは別々に決まります。上の会社の自己資本は160百万円で、発行済株式数が10万株なら、時価総額は株価2,500円で250百万円、1,200円で120百万円です。株価が変わっても、B/Sの数値は変わりません。この2つの比は、第10回でPBRとして扱います。

# P/L：期間の収益と費用

P/L（Profit and Loss statement、損益計算書）は、1年間などの期間に、どれだけの収益を得て、どれだけの費用を使ったかを表します。B/Sはある時点の残高、P/Lは期間中の流れです。

日本基準のP/Lは、利益を段階ごとに表示します。架空の会社の例です。単位は百万円です。

| 段階 | 計算 | 金額 |
|---|---|---:|
| 売上高 | | 1,000 |
| 売上総利益 | 売上高 − 売上原価700 | 300 |
| 営業利益 | 売上総利益 − 販売費及び一般管理費220 | 80 |
| 経常利益 | 営業利益 + 営業外収益15 − 営業外費用25 | 70 |
| 税金等調整前当期純利益 | 経常利益 − 特別損失10 | 60 |
| 当期純利益 | 税金等調整前当期純利益 − 法人税等18 | 42 |
| 親会社株主に帰属する当期純利益 | 当期純利益 − 非支配株主に帰属する利益2 | 40 |

各項目の意味です。

| 項目 | 意味 |
|---|---|
| 売上高 | 商品やサービスを売って得た収益の合計 |
| 売上原価 | 売った商品の仕入れや製造にかかった費用 |
| 売上総利益（粗利） | 売上高から売上原価を引いた、商品そのものの儲け |
| 販売費及び一般管理費（販管費） | 人件費、広告費、家賃など、売るためと会社を動かすためにかかった費用 |
| 営業利益 | 本業でどれだけ儲けたかを表す利益 |
| 営業外収益 | 受取利息や受取配当金など、本業以外で毎年発生する収益 |
| 営業外費用 | 支払利息など、本業以外で毎年発生する費用 |
| 経常利益 | 本業の利益に営業外の損益を加えた、会社全体の通常の儲け。日本基準だけにある段階です |
| 特別損失・特別利益（特別損益） | 災害損失や固定資産の売却損益のように、その年だけ起きた損益 |
| 税金等調整前当期純利益 | 税金を引く前の、最終的な利益 |
| 法人税等 | 利益にかかる税金 |
| 当期純利益 | 税引後の、その期の最終的な利益 |
| 非支配株主に帰属する利益 | 子会社の利益のうち、親会社以外の株主の取り分 |
| 親会社株主に帰属する当期純利益 | 当期純利益のうち親会社の株主の取り分。J-Quantsの `NP` にあたります |

段階を分けるのは、本業で稼げているか（営業利益）と、利息や一時的な損益で最終利益がどう変わったか（経常利益から先）を分けて読むためです。営業利益は黒字なのに純利益が赤字なら、本業以外のどこかに原因があります。

経常利益は日本基準にだけある段階です。IFRS（International Financial Reporting Standards、国際会計基準）で決算をするトヨタの決算短信には、営業収益、営業利益、税引前利益、当期利益、親会社の所有者に帰属する当期利益が並び、経常利益の欄はありません。

## 連結と単体、親会社株主に帰属する利益

連結決算は、親会社と子会社をまとめて1つの会社とみなして作った決算です。単体決算は、親会社だけの決算です。

連結の当期純利益には、子会社の利益のうち親会社以外の株主の分も入っています。それを除いたのが、親会社株主に帰属する当期純利益です。

# C/Fと減価償却

## 3つのキャッシュ・フロー

C/F（Cash Flow statement、キャッシュ・フロー計算書）は、期間中の現金の出入りを3つに分けます。

- 営業活動によるキャッシュ・フロー：本業で入った現金と出た現金
- 投資活動によるキャッシュ・フロー：設備の購入や売却、他社への投資
- 財務活動によるキャッシュ・フロー：借入と返済、株式の発行、配当の支払い

P/Lは、売ったときに売上を、使ったときに費用を記録します（発生主義）。C/Fは、現金が動いたときに記録します。小売店の例の売掛金や、次の減価償却で、利益と現金の動きがずれます。

## 200,000円の機械を4年間使う

20万円・耐用年数4年の機械を、次の条件で計算します。

- 資本金200,000円の現金で始め、1年目の初めに200,000円の機械を現金で買います。
- 耐用年数は4年、残存価額は0、定額法です。毎年の減価償却費は 200,000 ÷ 4 = 50,000円です。
- 機械を使って、毎年80,000円を現金で売り上げます。ほかの費用と税金はありません。

各年の数値は次のとおりです（円）。

| 年 | P/L 減価償却費 | P/L 純利益 | C/F 営業 | C/F 投資 | B/S 現金 | B/S 機械の簿価 | B/S 資産合計 | B/S 純資産 |
|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 1 | 50,000 | 30,000 | 80,000 | -200,000 | 80,000 | 150,000 | 230,000 | 230,000 |
| 2 | 50,000 | 30,000 | 80,000 | 0 | 160,000 | 100,000 | 260,000 | 260,000 |
| 3 | 50,000 | 30,000 | 80,000 | 0 | 240,000 | 50,000 | 290,000 | 290,000 |
| 4 | 50,000 | 30,000 | 80,000 | 0 | 320,000 | 0 | 320,000 | 320,000 |

機械の代金は、現金としては1年目に全額出ていき、費用としては4年間に分けて記録されます。

- P/L：毎年、減価償却費50,000円が費用になり、純利益は30,000円です。
- C/F：代金200,000円は、1年目の投資活動に出ます。営業活動のキャッシュ・フローは、純利益に減価償却費を足し戻した80,000円です。減価償却費は、その年に現金が出ていかない費用だからです。
- B/S：機械の簿価は毎年50,000円ずつ減り、4年目の終わりに0になります。減価償却費の累計（減価償却累計額）は、機械の簿価を減らす形でB/Sに残ります。現金は毎年80,000円増え、機械の簿価は50,000円減るので、資産合計は差し引き30,000円、つまり純利益の分だけ増えます。純資産も、資本金200,000円に純利益の累計を足した分だけ増えます。

負債は0なので、どの年も資産合計と純資産が一致し、資産＝負債＋純資産が成り立ちます。Codexに耐用年数や売上を変えて表を作るよう頼むと、利益と現金残高がどう変わるかを比べられます。

機械の代金を1年目に全部費用にすると、1年目の利益は-120,000円、2〜4年目は80,000円になります。4年間の合計は、減価償却をした場合と同じ120,000円です。減価償却は、4年間使う機械の費用を、その機械が売上を生む4年間に割り当てる記録の仕方です。

減価償却費は、P/Lの費用です。純資産に足す項目ではありません。この例で純資産が毎年増えるのは、純利益30,000円が利益剰余金に加わるからです。

# 決算サマリーの取得と照合

## 決算短信

決算短信は、上場会社が決算の内容をまとめて公表する書類です。東証の規則で、決算期末から45日以内に出すことになっていて、四半期ごとにも出します。1ページ目がサマリーで、売上高・営業利益・純利益、総資産・純資産、1株当たりの利益と純資産、配当、次の期の業績予想が並びます。2ページ目以降に、B/S・P/L・C/Fの本体が付きます。

決算短信は監査が終わる前の速報です。株価が反応するのは、数値が最初に公表される決算短信の方です。実物は各社のIRページで読めます。[トヨタ自動車の決算情報のページ](https://global.toyota/jp/ir/financial-results/)を開くと、四半期ごとの決算短信がPDFで並んでいます。2026年3月期の決算短信（2026年5月8日）の1ページ目を見ておくと、この先の表と列名の対応が追いやすくなります。第9回では、この1ページ目の数値をJ-Quantsから取得し、原資料と照合します。

決算短信と、監査を受けた正式な書類である有価証券報告書、J-Quantsの決算サマリーを並べると、次のようになります。

| | J-Quantsの決算サマリー | 決算短信 | 有価証券報告書 |
|---|---|---|---|
| 何か | 決算短信の1ページ目と業績予想の修正の数値を、開示ごとに1行にしたデータ | 取引所の規則による決算の速報 | 金融商品取引法による正式な報告書 |
| 時期 | 開示と同じ日 | 期末から45日以内、四半期ごと | 期末から3か月以内、年1回 |
| 監査 | ― | 監査の前に出る | 監査を受けている |
| 中身 | 主要な数値 | サマリーと財務諸表 | 財務諸表と注記、事業の内容、リスクなど |
| 入手先 | J-Quants API | 各社のIRページ、TDnet | 各社のIRページ、EDINET |

## J-Quantsの決算サマリー

J-Quantsの `/fins/summary` は、決算短信の1ページ目（サマリー）の数値を、開示ごとに1行で返します。第8回の株価と同じく、銘柄コードを送るとJSONで返り、pandasの表になります。取得のcodeは第8回の `toyota_oct2025.py` と同じ形で、`workbook/workbook.py` の6節に書いてあります。実行するたびにAPIへ問い合わせるので、開示が追加・訂正されていれば、行や数値が前回と変わります。

```python
fins = fetch("/fins/summary", {"code": "72030"})
```

トヨタ自動車では、2024年8月1日から2026年5月8日までの8回の開示が、8行で返りました（2026年9月17日取得、Freeプラン）。行を読むときは、まず次の列を見ます。

| 列 | 内容 | トヨタの2026年5月8日の行 |
|---|---|---|
| `DiscDate` | 開示日 | 2026-05-08 |
| `DocType` | 書類の種類（期間、連結・単体、会計基準） | `FYFinancialStatements_Consolidated_IFRS` |
| `CurPerType` | 期間の種類（1Q、2Q、3Q、FY） | FY |
| `CurPerSt`、`CurPerEn` | 期間の初日と末日 | 2025-04-01、2026-03-31 |

金額の列は円単位です。`Sales` は売上高、`OP` は営業利益、`OdP` は経常利益、`NP` は親会社株主に帰属する当期純利益、`TA` は総資産、`Eq` は純資産、`EqAR` は自己資本比率です。`EPS`（Earnings per Share）は1株当たり純利益、`BPS`（Book-value per Share）は1株当たり純資産で、自己資本を株数で割った値です。`DivAnn` は1株当たりの年間配当（円）です。1株当たりの数値と株価の倍率は、第10回で扱います。

`DocType` の `Consolidated` は連結、`NonConsolidated` は単体です。トヨタはIFRSなので、経常利益 `OdP` は空欄です。

## Codexに取得を頼む

```text
J-Quantsで、トヨタ自動車の決算サマリーを取得したいです。
開示日・書類の種類・期間の種類・期間の初日と末日・売上高・営業利益・純利益・総資産・純資産を表にして。
金額は百万円にし、開示日の順に並べて。
データとコードを保存し、後から同じ表を作れるようにして。
APIキーはチャットに貼らずに使いたいです。
```

列の意味が分からなければ「この行のDocTypeが何を表すか、このデータを使って説明して」と頼めます。「日産自動車とイオンも加えて、3社の直近2期の通期の行だけを並べて」のように、次に知りたいことを続けて頼むこともできます。

## 四半期は累計、実績と予想は別の列

四半期の行は、事業年度の初めからの累計です。トヨタの2026年3月期の3Q（2026年2月6日開示）の売上高は、2025年4月から12月までの9か月分です。通期から3Qを引くと、1〜3月の3か月分は約12.6兆円です。

`Sales` や `NP` は実績です。`FSales`、`FNP` など `F` で始まる列は、その事業年度の通期についての会社の予想です。通期の行では `F` の列が空欄で、翌事業年度の予想が `NxFSales` などに入ります。トヨタの2026年5月8日の行では、2027年3月期の売上高の予想が51兆円です。

## 業績予想の修正と、同じ期間の2つの行

決算短信とは別の日に、業績予想だけを修正する開示もあります。`DocType` が `EarnForecastRevision` の行で、実績の列は空欄です。日産自動車では、17行のうち9行がこの行でした。

同じ期間の行が2つあることもあります。イオンの2026年2月期の3Qの行は、開示日2026-01-08と2026-01-14の2つがあり、数値は同じでした。サマリーの行だけでは、2つ目の行が出た理由はこれだけでは分かりません。開示番号 `DiscNo` で行を区別し、企業のIRページの開示一覧で確かめます。（実際に調べると、監査法人によるレビューの遅れによるようです）

## 決算短信と照合する

決算短信との照合も、Codexに頼めます。

```text
トヨタ自動車の公式IRサイトから、2026年3月期の決算短信（2026年5月8日）を探して。
1ページ目の営業収益・営業利益・親会社の所有者に帰属する当期利益・資産合計・資本合計を読み取り、
J-Quantsの2026年5月8日の行の値と並べた表にして。単位は百万円にそろえて。
各項目が決算短信のどの欄にあたるかと、出所のURLも付けて。
一致しない項目があれば、推測で直さずに、その項目と両方の値を示して。
```

トヨタの2026年3月期の決算短信（2026年5月8日）の1ページ目と、J-Quantsの値を並べました。単位は百万円です。

| J-Quantsの列 | 決算短信の項目 | 決算短信 | J-Quants |
|---|---|---:|---:|
| `Sales` | 営業収益 | 50,684,952 | 50,684,952 |
| `OP` | 営業利益 | 3,766,216 | 3,766,216 |
| `NP` | 親会社の所有者に帰属する当期利益 | 3,848,098 | 3,848,098 |
| `TA` | 資産合計 | 105,522,331 | 105,522,331 |
| `Eq` | 資本合計 | 41,020,068 | 41,020,068 |

5項目とも一致しました。照合で確かめるのは、数値が同じかどうかと、列がどの項目にあたるかの2つです。`NP` は当期利益ではなく親会社の所有者の分、`Eq` は親会社の所有者に帰属する持分（39,918,854百万円）ではなく資本合計でした。

## 決算短信・有価証券報告書の明細を取得する

決算サマリーに入っているのは、決算短信の1ページ目に載る主要な数値です。売上原価や販管費、現金や借入金などの明細が必要な場合は、AIに企業の公式IRサイトから決算短信や有価証券報告書を取得し、表にまとめてもらえます。明細の取得には、J-Quantsを使う必要はありません。

```text
トヨタ自動車の公式IRサイトから、2026年3月期の有価証券報告書を探して。
連結貸借対照表と連結損益計算書の明細を、前期と当期を並べたCSVにして。
項目名と単位を残し、出所のURLとページ番号も付けて。
読み取れない数値は推測せず、その箇所を教えて。
```

出来上がった表を原資料と比べ、年度・単位・合計額が合っているかを確かめます。違いがあれば、該当箇所をAIに示して修正を頼みます。

トヨタ・日産・イオンの直近2期の通期の行を並べると、次のことが分かります（作例 `example/`）。日産は2期とも純利益が赤字で、2026年3月期は-5,331億円でした。イオンは2025年8月28日に1株を3株に分割したので、1株当たり純資産 `BPS` が2025年2月期の1,218.63円から2026年2月期の440.40円に下がっています。1株当たりの値は、分割の前後でそのままでは比べられません。

### 実作業例：公式IRサイトから明細をCSVにする

上の依頼で、[トヨタ自動車の2026年3月期有価証券報告書](https://global.toyota/pages/global_toyota/ir/library/securities-report/archives/archives_2026_03.pdf)から、次の2つのCSVを作成しました（2026年9月22日取得）。トヨタはIFRSを採用しているため、貸借対照表に当たる表の名称は「連結財政状態計算書」です。

# この回の要点

- 利益が出ていても、売掛金や在庫の分だけ現金は少なくなります。運転資金＝売掛金＋在庫－買掛金です。
- 機械の代金は、C/Fでは買った年の投資活動に、P/Lでは減価償却費として使う年数に分けて出ます。どの年も資産＝負債＋純資産です。
- J-Quantsの決算サマリーは決算短信の主要な数値です。`DocType`、期間、実績と予想の列を確かめてから使い、決算短信と照合します。
