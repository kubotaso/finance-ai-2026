## 2. 小さなファイルを作り、プレビューする

Codexは、指示をもとにファイルを読み書きし、必要な処理を実行します。最初に、入力欄の設定を確認します。

### Model・Effort・Speed

- Modelは、作業を行うAIの種類です。Astraは複数の工程を含む難しい作業、Solは日常的な作業や分析、Lunaは手順が明確な繰り返し作業に向きます。
- Effortは、どの程度深く考えるかの設定です。まず画面の初期設定から始めます。高くすると、時間や使用量が増えることがあります。
- Speedは処理速度の設定です。この宿題では `Standard` を使います。`Fast` は対応するモデルを速く動かしますが、使用量が増えます。

### Permissions（権限）

Permissionsは、Codexが作業できる範囲と、追加の操作を誰が承認するかの設定です。

| 設定 | 作業できる範囲 | 追加の操作の承認 |
|---|---|---|
| `Ask for approval`（承認を求める：自分で判断） | 作業フォルダ内のファイル編集や通常の処理を進めます | インターネット利用や作業範囲を超える操作は、人間に確認します |
| `Approve for me`（代わりに承認：AIが判断） | `Ask for approval`（承認を求める：自分で判断） と同じ作業範囲から始めます | 追加の操作を別のAIが審査します。審査を誤る場合もあります |
| `Full access`（フルアクセス） | PC上の広い範囲のファイルやインターネットへアクセスします | 個々の操作について人間の承認を求めずに進めます |

この講義では基本的に `Approve for me`（代わりに承認：AIが判断） を使います。承認画面が表れた場合は、操作の内容と対象を確認します。分からない場合は、その操作が必要な理由をCodexに聞けます。

### MarkdownとPDFをプレビューする

Codexに次のように指示します。

```text
仙台市内の美味しい醤油ラーメンのお店を調べて、preview_test.mdに表でまとめて。
```

作成された `preview_test.md` を開きます。リンクがでると思うので、それをクリックするとPreview（プレビュー）が開きます。ファイルを完成時に近い見た目で表示する機能です。見出しと表が表示されるか確認します。

### 音声機能を使ってみる

醤油ラーメンの表をプレビューしたら、ChatGPTアプリでこのタスクを開きます。入力欄の右側にある縦線が並んだ黒いボタンにカーソルを合わせ、「Start voice chat」と表示されたらクリックします。初回はマイクの使用を許可します。まず「こんにちは」と話しかけ、挨拶が返ってくることを確認します。その後、次のように話しかけます。

```text
preview_test.mdに仙台市内の美味しい豚骨ラーメンのお店も追加して。
```

音声認識で「豚骨ラーメン」やファイル名が正しく文字になっているか確認します。Codexが編集したら、`preview_test.md` のプレビューを開き直し、醤油と豚骨の店が表示されるか確かめます。

また、以下のような指示も出してください。教科書のページを確認できます。

```text

```

## 3. 第10章をまとめる

Codexに次のように指示します。


## 4. レポート作成に使うソフトを準備する

これから使うソフトの役割は、次のとおりです。

| ソフト | この宿題での役割 |
|---|---|
| winget | ソフトのインストールと管理に使います |
| Python | 公開データを取得・整理し、グラフを作ります |
| Node.js | JavaScriptで作られた道具をPC上で動かします |
| Marp CLI | MarkdownのスライドをPDFに変換します。Node.js上で動きます |
| Pandoc | MarkdownのレポートをWordやHTMLに変換します |
| Visual Studio Code | 原稿を開き、編集やプレビュー、Codexへの依頼を行います |

### 必要なソフトを入れる

この節の準備中は、入力欄の下にあるPermissionsを一時的に `Full access`（フルアクセス） に変更します。必ず、後で `Approve for me`（代わりに承認：AIが判断） に戻します。

Codexに次のように指示します。

```text
Git、Python、Node.js LTS、Pandoc、Visual Studio Codeをインストールして。
wingetが使える場合は利用し、使えない場合や手動操作が必要な場合は手順を教えて。
それぞれが使えることを確認して。
```

インストール後のソフトが見つからない場合は、アプリを開き直すと反映されることがあります。手動のインストール画面が出た場合は、画面の案内に沿って進めます。

### MarpとPythonの環境を準備する

```text
npmを使ってMarp CLIをインストールし、使えることを確認して。
```

Pythonで使うライブラリは、宿題フォルダの外にある `finance-env` にまとめます。後の講義で解説します。

```text
ドキュメント\金融論\finance-envにPythonの仮想環境を作って。
その仮想環境にpandas、matplotlib、requestsをインストールし、すべて読み込めることを確認して。
以後、この宿題のPython作業ではドキュメント\金融論\finance-env\Scripts\python.exeを使って。
```

`finance-env` は、この宿題で使うPythonの実行環境とライブラリをまとめたフォルダです。

ソフトのインストールとMarp・Python環境の動作確認が終わったら、入力欄の下にあるPermissionsを `Approve for me`（代わりに承認：AIが判断） に戻します。

## 5. Visual Studio Codeで同じフォルダを開く

Visual Studio Codeを開き、Codexで使っている `ドキュメント\金融論\HW01` を選びます。`moc_text.pdf` と `chapter10_summary.md` が一覧に並びます。

拡張機能は、Visual Studio CodeにAIとの対話やスライド作成などの機能を追加するためのものです。

左側のパネルにある「拡張機能」アイコンをクリックすると、拡張機能画面が開きます。この画面から、次をインストールします。

- `openai.chatgpt`（Codex）
- `marp-team.marp-vscode`（Marp）

Codexのアイコンを開き、ChatGPTアカウントでサインインします。ここでのサインインはCodexを使うためのものです。[OpenAI DocsのIDE拡張機能](https://learn.chatgpt.com/docs/codex/ide)

ここからは、Visual Studio CodeのCodexを使います。

### 原稿と保存の印を見る

`chapter10_summary.md` を開き、`Ctrl + Shift + V` でプレビューを表示します。マウスで操作する場合は、画面上部の `chapter10_summary.md` のタブを右クリックし、「プレビューを開く（Open Preview）」を選びます。元の文章と、見出しや箇条書きの表示を比べます。

手作業で編集した内容が未保存の場合、タブには●が表示されます。`Ctrl + S` で保存すると、変更がファイルへ反映されます。保存してからCodexに依頼すると、編集した内容を読み取れます。

PDFはPDFを表示できるアプリで開けます。VS Code内で表示する場合は、PDF表示用の拡張機能 `vscode-pdf` を使えます。

### ファイルや行をCodexに見せる

見てほしい行を選び、右クリックの `Add to Codex Thread` から会話に追加します。ファイル全体は、タブの `Add File to Codex Thread` から追加できます。メニューが見つからない場合は、ファイル名と対象の見出しを指示に書くと、場所を伝えられます。

`Add File to Codex Thread` には、キーバインド（ショートカットキー）を割り当てておくと便利です。設定方法はCodexに聞けます。

## 7. 第10章のレポートを作る

Markdownの原稿からWordとHTMLを作ります。文章を直す場所は `chapter10_report.md` です。原稿を直した後は、WordとHTMLも作り直すと内容が揃います。

```text
moc_text.pdf、chapter10_summary.md、data_updateフォルダの更新した図表を使って、第10章の短いレポートを作って。
原稿はchapter10_report.md、AIに依頼した作業の記録はAI_LOG.mdにまとめて。
```

次のファイルを開いて確認します。

- `chapter10_report.md`：レポートの原稿です。
- `AI_LOG.md`：依頼した作業の記録です。
- `output/chapter10_report.docx`：提出するWordレポートです。
- `output/chapter10_report.html`：ブラウザで読めるレポートです。

### コラム：LibreOfficeを使う方法もあります

オープンソースのオフィススイートであるLibreOfficeを導入すると、WordファイルをPDFに変換し、Codexにレイアウトの確認を依頼することもできます。導入や使い方はCodexに聞けます。MS Wordとは表示が異なる場合があるため、提出前にはMS Wordでも確認します。
