1. 株式と市場

株を買うとは

株式は、会社の持分です。普通株の株主には、株主総会で議決に参加する権利、配当を受け取る権利、会社を清算したときに残った財産の分配を受ける権利があります。配当の金額は決まっておらず、配当がない年もあります。会社が倒産した場合、株主に財産が残らないこともあります。

会社が新しい株を発行して投資家に買ってもらうと、会社に資金が入ります。一方、取引所で既存の株を買うと、代金はその株を売った投資家に渡ります。日々の株式売買と、会社が直接資金を調達する場面は別です。

株式を売れる市場があると、投資家は必要なときに現金へ戻しやすくなります。会社が資金を集める仕組みを、流通市場が支えています。

普通株式には、あらかじめ定めた満期や固定利息がありません。株主の責任は原則として出資額の範囲に限られ、会社の借金を株主個人が追加で返す義務は負いません。これが有限責任です。

上場、増資、株式分割

会社へ新しい資金が入るかどうかに着目すると整理できます。

言葉 何が変わるか 会社に資金が入るか
上場 取引所で株式を売買できるようになります 上場そのものとは別に、新株の公募を伴えばその払込金が入ります
公募増資 広く投資家を募り、新株を発行します 入ります
第三者割当増資 特定の相手に新株を割り当てます 払込みを受けます
株式分割 1株を複数株に分けます 分割だけでは入りません

上場時に既存の株主が持ち株を売り出す場合、その代金は売った株主へ渡ります。会社による新株発行とは区別します。資金調達と財務諸表への記録は第8回で詳しく扱います。

日本の株式市場

日本の株式のほぼ全部は、東京証券取引所（東証）で売買されています。東証は日本取引所グループ（JPX）の一部で、同じグループに先物やオプションを扱う大阪取引所があります。名古屋・札幌・福岡にも取引所がありますが、単独上場の会社は少数です。3節で使うJ-Quantsを運営するJPX総研も、このグループの会社です。

東証の市場は、2022年4月からプライム・スタンダード・グロースの3つに分かれています。プライムは大きな会社向け、グロースは上場して間もない成長企業向けで、上場の基準が違います。上場会社数は次のとおりです。

市場 上場会社数
プライム 1,548
スタンダード 1,562
グロース 599
合計（TOKYO PRO Marketを含む） 3,897

出所：JPX「上場会社数・上場株式数」、2026年9月18日時点。

取引は、平日の9時から11時30分（前場）と12時30分から15時30分（後場）に行われます。土日、祝日、12月31日から1月3日は休みです。売買の単位は100株です。株価1,000円の株なら、最低10万円からの取引になります。約定した売買の代金と株式の受け渡しは、約定日の2営業日後です。

上場会社には4桁の証券コードが付いています。トヨタ自動車は7203、日産自動車は7201、イオンは8267です。J-Quantsのデータでは末尾に0を付けた5桁（72030）で表されます。第6回の架空データの 01110 も、この5桁の形に合わせたものです。

投資家の顔ぶれでは、売買代金の6割前後を海外の投資家が占めています。保有では、海外投資家、信託銀行（年金や投資信託の資産を預かる）、事業会社、個人がそれぞれ1〜3割です。売買の主役と持ち主が違うことは、株価の動きを読むときに頭に入れておく点です。

株価は注文が出会って決まる

売りたい人と買いたい人が、価格と数量を指定して注文します。価格を指定する注文を指値注文、価格を指定せず売買する注文を成行注文といいます。成行注文では、画面で見た直前の株価と違う価格で約定することがあります。

次は、取引時間中の注文を簡略化した架空の例です。

売りたい数量 価格 買いたい数量
200株 1,010円 —
100株 1,005円 —
— 1,000円 300株
— 995円 200株

最も安い売り注文は1,005円、最も高い買い注文は1,000円です。この状態では条件が合わず、まだ取引は成立しません。新たに100株の成行買い注文が来れば、他の注文が変わらない限り、1,005円の売り注文と取引が成立します。

買いたい数量が増えると、安い売り注文から順に取引され、より高い価格へ進むことがあります。売りが増える場合は逆です。実際には注文の追加・取消しが続きます。寄付きや引けでは、注文をまとめて処理する仕組みも使われます。

「市場が株価を決める」とは、誰かが会社の正しい価値を計算して公表するという意味ではありません。異なる予想を持つ人の注文が出会い、取引価格が記録されるという意味です。

株価と時価総額

株価は1株の価格です。会社の株式全体に対する市場評価を見るときは、時価総額を使います。

時価総額=株価×発行済株式数 \text{時価総額} = \text{株価} \times \text{発行済株式数}

架空の会社 株価 発行済株式数 時価総額
A社 1,000円 1億株 1,000億円
B社 5,000円 1,000万株 500億円

B社の株価は高くても、時価総額はA社より小さくなっています。

1株を2株に分ける株式分割では、株数が2倍になり、他の条件が変わらなければ1株の価格は半分になります。株主が持つ株式全体の価値は、それだけでは変わりません。長い期間の株価を比べるときに「調整済み」という列が必要になる理由です。

株価指数は市場全体を見る物差し

TOPIXや日経平均株価は、複数の銘柄の値動きをまとめた指標です。日経平均株価は、日本経済新聞社がプライム市場から選んだ225銘柄の株価を平均したもので、株価の高い銘柄の影響が大きくなります。TOPIXは、東証が算出する時価総額で重みを付けた指数で、対象は約2,000銘柄です。1社の株価が下がった日でも、市場全体が下がったのか、その会社だけが下がったのかで読み方が違います。指数によって対象銘柄や重みの付け方が違うため、値動きも一致しません。今回は指数を作る計算には立ち入りません。

2. 将来の受取額から株式を評価する

株主が受け取るお金

株式を持つ間には配当を、売るときには売却代金を受け取ります。配当は会社が株主に分配するお金です。会社の利益のすべてが配当になるわけではなく、事業のために会社に残す分もあります。

配当の金額や回数は会社によって異なります。年1回の会社も、中間配当と期末配当の年2回に分ける会社もあります。毎年必ず受け取れるわけではなく、配当が減ったり、なくなったりすることもあります。

例えば、1株当たりの中間配当が20円、期末配当が30円なら、両方の対象となる100株について、税引前で2,000円と3,000円、年間合計5,000円を受け取ります。対象となる株主を決める日が権利確定日で、実際の支払日はそれより後です。日本取引所グループでは、3月末と9月末の株主を対象に年2回の配当を行っています。

1年後の受取額を今日の価値に直す

将来受け取るお金を今日の価値に直したものを、現在価値といいます。今日の100円が年5%で増えると、1年後には105円になります。逆に、1年後の105円を5%で割り引くと、今日の100円に相当します。

株式でも、予想する配当と売却代金を割り引いて評価します。割引率は、その株式のリスクを引き受ける投資家が求める収益率です。以下では計算用に5%と仮定します。手数料と税金は省きます。

架空の株式1株について、1年後に配当5円を受け取り、その直後に107円で売ると予想します。1年後の受取額は合計112円なので、今日の評価額は次のようになります。

V0=5+1071.05≃106.67円 V_0 = \frac{5+107}{1.05} \simeq 106.67\text{円}

V0V_0 は今日の評価額です。106.67円は、この予想と割引率から計算した値であり、市場で実際に売買される価格とは限りません。配当も売却価格も、予想どおりになるとは限りません。

第5回の present_value で書くと、次の2行です。

def present_value(amount, rate, years):
    return amount / (1 + rate) ** years

print(round(present_value(5 + 107, 0.05, 1), 2))   # 106.67

予想や割引率を変えると評価額が変わる

同じ1年後の受取りについて、条件を変えて計算します。

条件 予想配当 予想売却価格 割引率 今日の評価額
基準 5円 107円 5% 106.67円
割引率だけを変更 5円 107円 10% 101.82円
配当だけを変更 8円 107円 5% 109.52円
配当と売却価格を変更 8円 113円 5% 115.24円

ほかの条件が同じなら、予想する受取額が大きいほど評価額は高くなります。同じ受取額でも、高い収益率を求めるほど、今日支払ってよいと考える金額は低くなります。

投資家によって予想や求める収益率が違うため、同じ株式でも評価額は異なります。

この表をCodexに作らせるなら、次のように頼みます。

架空の株式1株について、1年後に配当5円を受け取り、その直後に107円で売ると予想している。
割引率5%と10%で今日の評価額をPythonで計算し、条件と結果を表にして。
配当を8円にした場合と、配当8円・売却価格113円の場合も同じ表に加えて。
手数料と税金は省き、計算式と結果の意味も短く説明して。
コードと結果を保存して。

返ってきた表で、配当と売却代金がどちらも1年後の受取りとして1回だけ割り引かれているか、基準の行が106.67円になっているかを見ます。違っていたら、その箇所と意図した条件を伝えて直してもらいます。「なぜ割引率を上げると評価額が下がるのか、この数値で説明して」と頼むと、表の読み方も返ってきます。

複数年持つ場合は、受け取る年ごとに割り引く

3年間持ち、毎年末に1株当たり5円の配当を受け取り、3年後の配当受取直後に107円で売ると予想します。割引率が年5%なら、評価額は次のようになります。

V0=51.05+51.052+5+1071.053≃106.05円 V_0 = \frac{5}{1.05} + \frac{5}{1.05^2} + \frac{5+107}{1.05^3} \simeq 106.05\text{円}

1年後の配当は1年分、2年後の配当は2年分、3年後の配当と売却代金は3年分割り引きます。ここでは計算を簡単にするため、1年分の配当を各年末にまとめて受け取ると仮定しています。

保有期間を TT 年、tt 年後の予想配当を DtD_t、最後の配当受取後の予想売却価格を PTP_T、一定の割引率を rr とすると、同じ計算を次の式で表せます。

V0=∑t=1TDt(1+r)t+PT(1+r)T V_0 = \sum_{t=1}^{T} \frac{D_t}{(1+r)^t} + \frac{P_T}{(1+r)^T}

各年の配当を割り引いて足し、最後に売却代金の現在価値を足しています。売った後の配当は、その株式を買った人が受け取るため、ここには加えません。第5回の7-3で、毎年1万円を5年間受け取る現在価値を for で足したのと同じ計算です。

毎年末に5円の配当を受け取り、3年後の配当受取直後に107円で売る場合の今日の評価額を、
割引率5%で計算して。年ごとの現在価値と合計を表にして。

年ごとの行が3つあり、3年目の行だけ配当と売却価格の両方が入っていて、合計が106.05円になっていれば正しく計算されています。

実際に得た収益率を計算する

購入後に実際に得た収益率は、購入価格と受取額から計算します。100円で買い、1年後に配当5円を受け取り、107円で売れた場合、収益率は12%です。

5+107−100100=0.12 \frac{5+107-100}{100}=0.12

配当5円と値上がり益7円を、支払った100円で割っています。先ほどの評価計算は、将来の予想から今日の評価額を求めるものでした。こちらは、実際の購入価格と受取額から運用の結果を求める計算です。

3. APIで株価を取得する

APIはプログラム同士をつなぐ窓口

APIはApplication Programming Interfaceの略で、あるプログラムの機能やデータを、別のプログラムから利用するための窓口です。何をどの形式で渡すと、どのような結果が返るかが決められています。天気の取得、地図の検索、文章の翻訳などにも使われます。

この授業では、インターネットを通じてサービスに依頼を送るWeb APIを使います。ブラウザでは人が入力欄やボタンを操作しますが、Web APIではプログラムが決められた形式で依頼を送ります。この依頼をリクエスト、サービスからの返答をレスポンスと呼びます。リクエストの中身は、URLに条件を付けたものです。例えば「銘柄コード72030、2025年10月1日から31日まで」という条件を付けて送ると、その条件に合う日々の株価が返ってきます。

返答は、人が読む画面ではなく、第6回で見たJSONの形式で届きます。1日分が {"Date": "2025-10-01", "Code": "72030", "C": 2821.5} のような列名と値の組で、それが [ ] に並んで "data" の下に入っています。pandasはこの並びをそのまま表（DataFrame）に直せるので、第6回でCSVを読んだあとと同じ操作ができます。取得した値を手でコピーせず、そのまま集計や作図につなげられ、同じ処理を別の銘柄や期間に繰り返せるのがAPIを使う利点です。

APIによっては、利用者を識別し、利用権限を確認するためにAPI keyを使います。API keyは英数字が並んだ文字列で、パスワードと同じ扱いをします。他の人に使われるのを防ぐため、Codexへの依頼文、notebook、原稿、提出物には書きません。この授業では、keyを 金融論 フォルダの api_key.txt に保存し、プログラムがそこから読む形にします。API keyが不要なAPIもあり、コラムの3つはどれも不要です。

J-Quants

J-QuantsはJPX総研が提供する、株価や企業の財務情報などのサービスです。上場銘柄の一覧、日々の四本値、財務情報などを、APIから取得できます。この教材ではV2のAPI key方式を使います。

無料プランでは直近12週間のデータを取得できません。授業では、無料プランの範囲に入る2025年10月を例にします。料金・期間・回数の条件は、公式のプラン一覧に掲載されています（2026年9月17日確認）。

アカウントの作成、Freeプランの登録、API keyの発行と保存は、J-Quants APIの準備の手順で授業前に済ませておきます。keyは、各回の LectureXX フォルダをまとめている 金融論 フォルダの api_key.txt に保存します。この回の作業は、その中の Lecture07 フォルダで進めます。

銘柄と期間を変えるときは、2段目の CODE、START、END を書き換えます。図のタイトルの会社名は英語で直書きしてあるので、そこも直します。Codexに「日産自動車の2025年9月に変えて」と頼めば、この3か所と図のタイトルをまとめて直してくれます。

取得したデータの扱いは次の節のとおりです。output/ のCSVは自分の手元で使い、提出物や共有folderには入れません。

表に出てくる列

列 内容
Date、Code 取引日、銘柄コード
O、H、L、C 始値、高値、安値、終値。調整前の価格です
Vo 出来高。売買された株数です
AdjC 調整済み終値。株式分割・併合等に対応する列です

列の名前は第6回の架空データと同じです。始値はその日の最初の取引価格、終値は最後の取引価格です。高値と安値はその日の取引価格の最大・最小です。休場日には取引がないので行がありません。行がない日を、株価が0円の日として扱うことはできません。

調整済み終値は、その日に実際に売買できた価格とは限りません。また、分割調整と、配当を含めた投資収益は別のものです。今回の図は価格の推移であり、配当込みの収益率ではありません。調整の対象は公式仕様で確認します。

取得したデータの扱い

APIで取得できることと、取得データを配布できることは別です。公式FAQでは、取得データそのものを閲覧できる形で配布・共有することが禁止されています。HW02で提出するのは、取得の条件、集計した表、図、codeで、取得した元データのCSVと api_key.txt は含めません。

この回のまとめ

市場の株価は注文が出会って決まります。投資家が考える価値は、将来の受取額と割引率などの仮定によって変わります。

APIは、条件を送ると決まった形式でデータが返ってくる窓口です。J-Quantsから取得した株価は、列・単位・調整の意味を確かめてから表と図を読みます。
