# J-Quants APIの準備：アカウント登録とAPIキーの保存

確認日：2026年10月29日

## この手順で準備するもの

各自のJ-Quantsアカウントを作り、発行したAPIキーを、各回の `LectureXX` フォルダをまとめている **`金融論` フォルダ**の `api_key.txt` に保存します。各回のPythonコードは、この共通ファイルからキーを読み込みます。

APIキーは、プログラムからJ-Quantsを利用するときの認証に使います。ログイン用パスワードや、メールに届く認証コードとは別のものです。自分のキーを使い、他の人と共有しないでください。

## 1. J-Quantsのアカウントを作る

1. [J-Quants公式サイト](https://jpx-jquants.com/ja)を開きます。
2.「利用を始める」をクリック、またはSign in を選びます。
3. メールアドレスとパスワード、またはGoogleアカウントで登録します。

## 2. Freeプランに登録する

アカウント登録と利用プランの登録は別になります。
1. ログイン後、クイックスタートガイドが開いて「ご利用には、プラン登録が必要です（無料のFreeプランでもご利用いただけます）。 **プランを選ぶ** 」とあるのでクリック。または、ダッシュボード左側の **Subscription** をクリックします。
2. **Freeプラン（無料で登録）** を選びます。
3. 画面の案内に従って名前や住所も登録し、申し込みをします。

Freeプランのデータは12週間遅延して配信されます。直近の株価が取得できなくても設定ミスではありません。動作確認には、12週間以上前の株価を使ってください。

## 3. APIキーを発行する

1. ログイン後、ダッシュボードの **API Keys** を開きます。
2. 画面の案内に従ってAPIキーを発行します。
3. 発行されたAPIキーをコピーします。

## 4. 「金融論」フォルダの `api_key.txt` に保存する

1. VS Codeで、各回の `LectureXX` フォルダをまとめている **`金融論` フォルダ**を開きます。
2. 左側のエクスプローラーで `金融論` フォルダの直下に新しいファイルを作り、名前を **`api_key.txt`** にします。
3. ファイルの1行目に、自分のAPIキーを貼り付けて、保存します。

配置の例です。

```text
金融論/
├── api_key.txt
├── Lecture06/
│   ├── workbook.ipynb
│   └── data/
└── Lecture07/
    └── （この回の教材）
```

## 5. Pythonから読み込めることを確認する

各Lectureのフォルダで作業するとき、Codexに、以下のように言えば確認してくれます。

```text
J-QuantsのAPIキーが親フォルダかそのあたりにあるので、任天堂の株価を取得してプロットして、動くか試して
```

## 6. 課題を提出・共有するとき

**`api_key.txt` は自分のPCで使うファイルです。提出・共有しないでください。**

誤ってキーを公開した場合は、J-QuantsのAPIキー管理画面で **API Keyを再発行** して差し替えてください。
