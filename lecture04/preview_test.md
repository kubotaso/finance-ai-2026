# Codex設定テスト

- Model：指示を読んで考え、回答やファイルを作るAIの種類
  - Sol：複雑で曖昧な課題、深い分析、仕上がりを重視する作業に向く
  - Terra：日常的な作業を、性能と速さのバランスを取りながら進める
  - Luna：手順や完成形が明確な、短く反復的な作業に向く
- Effort：同じモデルにどの程度深く考えさせるか。`Light`、`Medium`、`High`、`Extra High`、`Max` があり、通常は `Medium` から始める
- Speed：`Standard` は通常の速度、`Fast` は速いがクレジットを多く使う。HW01では `Standard` を使う
- Prompt：変更するfile、場所、内容、確認方法を具体的に書く
