# AGENTS.md

## この課題

- このfolderでは、金融論のreport、図、data、再現用scriptを管理する。
- 回答と文書は日本語で書く。

## 保存先と原資料

- reportの原稿はprojectのroot、変換後のfileは `output/` に保存する。
- 図は `figures/`、scriptは `scripts/` に保存する。
- 配布されたPDFと `data/raw/` のfileは編集、移動、上書き、削除しない。
- projectの外にはfileを作らない。

## 出所と記録

- 数値、制度、引用には、資料名、URL、取得日を付ける。
- AIへ依頼した作業と採用した変更を `AI_LOG.md` に記録する。

## 実行前の確認

- 依頼で許可していない既存成果物の置換・削除、packageの追加、外部serviceへの書込みは実行前に確認する。今回の依頼に含まれる通常の編集・生成は、その範囲で進める。
- API key、password、個人情報をfileやchatへ書かない。

## 完了前の確認

- diffで指定外の変更がないことを確認する。
- 図表の数値と本文の説明が一致しているか確認する。
- 変更したfileと、実行した確認を最後に報告する。
